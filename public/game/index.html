遊び方

  • 漕ぐ速さで、採掘船のレーンが変わります。遅い / 基準 / 速い の 3 本です。
  • 基準レーン(目標 ±5 rpm)にいる間、鉱石が少しずつ貯まります。
  • ときどきレア鉱脈が来ます。速いレーンで掘ると大量に取れますが、エンジンの熱が上がります。熱が満タンになると 6 秒止まります。どこで戻るかの勝負です。
  • ときどき隕石群が来ます。遅いレーンに逃げてよけてください(ひと休みにもなります)。
  • 何も来ていないときに基準レーンから 3 秒以上外れると、コンボが切れます。コンボが続くほど、鉱石の量と音楽が増えます。
  • 区間の始めに「ノブを回してみよう」と出ます。回したら右下の「回した!」を押すと、その区間のドリルが強化されます。
  • 漕ぐのをやめると自動で一時停止します。
