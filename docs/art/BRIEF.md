# 絵の制作依頼(Codex 向け)

このリポジトリは、エアロバイクを漕いで遊ぶブラウザゲーム「ペダルリズム 宇宙採掘」です。
ゲームの仕組みと演出(ビーム・火花・破片・光)はできています。足りないのは**絵の素材**です。
いまの岩や船はコードで多角形を描いたもので、「図形の組み合わせ」にしか見えません。これを、画像生成で作った絵に差し替えます。

あなた(Codex)の仕事は、**下の一覧の画像を画像生成で作り、`public/game/assets/` に決まった名前で置くこと**です。

## 大事な決まり

- **画像生成の機能で作ること。** コードで図形を描いて画像にしてはいけません(SVG、Canvas、Pillow や ImageMagick の図形描画、プログラムで作ったノイズや模様は不可)。それをやると、今と同じ見た目になります。
- 画像生成の機能が使えない場合は、**何も作らずに、そのことを報告して止まってください。**
- 触ってよいのは `public/game/assets/` と `docs/art/NOTES.md`、`docs/art/preview.png` だけです。`public/game/index.html` などのコードは変更しないでください(画像の読み込みは実装済みです)。
- 生成後の縮小・トリミング・形式の変換・背景の透過処理に、ツール(Pillow など)を使うのは構いません。
- 文字、ロゴ、枠、UI、透かし、署名を絵に入れないでください。

## ゲーム画面での使われ方

- 舞台は暗い宇宙。画面奥から手前に 3 本のレーンが伸び、小惑星が流れてきます。手前に採掘船がいます。
- 画面は iPad の横置き(4:3)。小惑星は画面上で直径 60〜200 px くらい、船は高さ 110 px くらいで表示されます。**小さく表示しても形と種類が一目で分かること**が大事です。
- 小惑星の上には、ゲームがひび割れと光を重ねて描きます。船のエンジンの炎、彗星の尾、ビームもゲームが描きます。絵には入れないでください。
- ゲームは読み込んだ画像の余白を自動で切り詰め、中央にそろえます。多少のずれは問題ありません。

いまの画面(コードで描いた絵)は、`public/game/index.html` を開くと確認できます。

## 絵柄(全部の画像で統一する)

- **ハード SF のコンセプトアート風のデジタルペイント。** 写実寄りで、質感をしっかり描き込む。
- 光は**左上から**の強い一方向の光(やや青白い)。反対側の右下は深い影で、ふちに薄い紫のリムライト。
- 彩度は控えめ。ただし鉱石の色ははっきり出す(下の色を使う)。
- 禁止: フラットなベクター調、ローポリ、線画、アニメ塗り、ドット絵、絵文字風、3D レンダリングの安っぽい質感、玩具っぽさ。

| 種類 | 見た目 | 差し色 |
|---|---|---|
| 鉄 | ごつごつした暗い岩。さびた金属の鉱脈が走り、クレーターがある | 橙 `#ffa25c` |
| 氷 | 青白い氷のかたまり。割れ目と、半透明の層。霜 | 水色 `#8fe3ff` |
| 結晶 | 暗い岩から、光る紫の結晶が何本も突き出ている。結晶は内側から発光 | 紫 `#e58bff` |

## 作る画像

### 必須(まずこの 10 枚)

小惑星と船は **512×512 の PNG、背景は透明**。対象は中央に置き、枠の 85% くらいを占める大きさで、はみ出さないこと。1 枚 400 KB 以下。

| ファイル名 | 内容 |
|---|---|
| `ship.png` | 採掘船。**真上よりやや後ろから見下ろした図で、機首がまっすぐ上を向く。** 左右対称。工業的でずんぐりした小型の作業船(戦闘機ではない)。機首に採掘ビームの発射口、後部(下端)中央にエンジンのノズル。炎は描かない。機体は明るめのグレーで、暗い背景でも輪郭が分かること |
| `rock_iron_1.png` `rock_iron_2.png` | 鉄の小惑星。形違いで 2 種類 |
| `rock_ice_1.png` `rock_ice_2.png` | 氷の小惑星。形違いで 2 種類 |
| `rock_crystal_1.png` `rock_crystal_2.png` | 結晶の小惑星。形違いで 2 種類 |
| `comet.png` | 彗星の核。白く輝く氷と結晶のかたまりで、小惑星より明るく特別に見える。尾は描かない |
| `far.png` | 遠くに浮かぶ巨大な小惑星。全体に暗く、左上のふちだけ光が当たる。レーンの消失点に置く目印 |
| `bg.jpg` | 背景。**2048×1536 の JPG、700 KB 以下。** 星雲と星のある深宇宙。遠くに小惑星帯がうっすら見える。**画面の中央から下は暗く静かに**(その上にレーンと小惑星が描かれるため)。明るい星雲は上の左右に寄せる。大きな惑星や明るい星を中央に置かない |

小惑星の共通条件:
- 輪郭はいびつで良いが、**おおよそ丸い**こと(縦横比 1.25 以内)。ゲームが少し回転させ、中心からひびを描くため。
- 影や光が背景ににじまないこと。地面の影は描かない。
- 透明な背景にできない場合は、**背景を純粋な緑 `#00FF00` 一色**にしてください(対象に緑を使わない)。ゲーム側で緑を抜きます。黒い背景は不可(岩の影まで抜けてしまうため)。

## 作ったあとの確認(自分でやること)

生成した画像を 1 枚ずつ開いて見て、下を確認してください。満たさないものは作り直します(1 枚につき 3 回まで)。

- [ ] 図形の組み合わせではなく、描き込まれた絵に見える
- [ ] 10 枚を並べたとき、同じ画家が描いたように絵柄がそろっている
- [ ] 光が左上から当たっている
- [ ] 鉄・氷・結晶が、64 px に縮めても色と形で見分けられる
- [ ] 船の機首が上を向いている。炎がない
- [ ] 背景が透明(または緑一色)で、対象が切れていない
- [ ] 文字や枠が入っていない
- [ ] `bg.jpg` の中央から下が暗く、明るい物が置かれていない
- [ ] ファイル名・大きさ・容量が指定どおり

確認用に、**暗い背景(`#060818`)の上に全部の画像を並べた一覧**を `docs/art/preview.png` として作ってください(これは Pillow などで並べて構いません)。小惑星は 64 px に縮めたものも並べてください。

## 納品

1. 画像を `public/game/assets/` に置く。
2. `docs/art/NOTES.md` に、画像ごとの生成プロンプト、作り直した回数、自分で気になっている点を書く。
3. ブランチ `art/round-1` を作ってコミットし、push する(push できなければ、コミットまでで止めて報告)。

そのあと、ゲームを作っている側が画像を確認し、直してほしい点を `docs/art/REVIEW.md` に書きます。`REVIEW.md` がある場合は、**それを先に読み、指摘された画像だけを作り直して**ください(合格と書かれた画像は触らない)。その場合のブランチ名は `art/round-2`、`art/round-3` と増やします。
